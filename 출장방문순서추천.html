준비 중

장소 검색 설정

카카오에서 무료로 받은 JavaScript 키를 한 번만 입력하면 장소 검색을 쓸 수 있습니다.

REST API 키를 넣으면 동작하지 않습니다. 반드시 JavaScript 키를 복사하세요.

자동차 도로거리 (선택)

도로거리로 방문순서를 추천하려면 길찾기 서버가 필요합니다. 카카오 REST API 키는 서버에서만 다루며, 이 화면에는 입력하지 않습니다. 서버가 없으면 직선거리 모드로 그대로 쓸 수 있습니다.

예) http://localhost:8787 — 설정 방법은 docs/ROAD_DISTANCE.md 참고

키 발급 방법과 보안 안내 자세히 보기

키 발급

  1. developers.kakao.com 로그인 → 내 애플리케이션 → 애플리케이션 추가하기
  2. 앱 키 화면에서 JavaScript 키 복사
  3. 앱 설정 → 플랫폼 → Web → 사이트 도메인, 그리고 앱 키 → JavaScript SDK 도메인에 이 페이지 주소를 등록 (두 곳 모두)

JavaScript 키의 성격

  • 브라우저가 직접 쓰는 값이라 개발자도구로 누구나 볼 수 있습니다. 비밀값이 될 수 없습니다.
  • 그래서 등록한 도메인에서만 동작하도록 카카오가 막아 줍니다.
  • 키가 퍼지면 내 앱의 무료 사용량이 남에게 소모되어 업무 중 검색이 막힐 수 있습니다.
  • 사용량이 비정상적으로 늘면 개발자 사이트에서 키를 재발급하세요.

무료 사용량

카카오 정책에 따라 수시로 바뀌므로 여기에 적지 않습니다. 내 애플리케이션 → 쿼터 화면에서 직접 확인하세요. 출장 계획 용도(1회 검색 몇 건)로는 무료 범위를 넘기기 어렵습니다.

출발지와 출장지를 검색해 등록하면, 직선거리 합계가 가장 짧은 방문 순서를 추천합니다. 출장지는 최대 8곳입니다.

설정 · 카카오 JavaScript 키

장소 검색에는 카카오 지도 JavaScript 키가 필요합니다. 키는 무료로 발급받을 수 있으며, 발급 방법은 README 파일에 정리되어 있습니다.

JavaScript 키 취급 시 주의 JavaScript 키는 브라우저가 직접 사용하는 값이라 개발자도구·소스보기로 누구나 볼 수 있습니다. 비밀값으로 취급할 수 없으므로 다음을 꼭 지켜 주세요.
  • 카카오 개발자 사이트에서 사용할 도메인만 등록해 두면, 등록되지 않은 사이트에서는 그 키를 쓸 수 없습니다.
  • 키가 외부에 퍼지면 내 앱의 일일·월간 무료 사용량이 남에게 소모되어 업무 중 검색이 막힐 수 있습니다.
  • 사용량이 비정상적으로 늘면 개발자 사이트에서 키를 재발급(교체)하세요.
  • REST API 키는 이 프로그램에서 사용하지 않습니다. 절대 입력하거나 파일에 적어 두지 마세요.
참고 · 사용량 무료 사용량(쿼터)은 카카오 정책에 따라 바뀔 수 있습니다. 현재 내 앱에 적용된 값은 카카오 개발자 사이트의 내 애플리케이션 → 쿼터 화면에서 직접 확인하세요. 일반적인 출장 계획 용도(1회에 검색 몇 건)로는 무료 범위를 넘기기 어렵습니다.

추천 방문순서

직선거리 기준 추천이며 실제 자동차 최단경로와 다를 수 있습니다. 두 지점을 잇는 직선거리(Haversine) 합계가 가장 짧은 순서를 계산한 결과입니다. 실제 도로·교통상황·일방통행·강이나 산 등은 반영하지 않으며, 주행시간이나 소요시간도 계산하지 않습니다. 최종 출장 계획은 카카오맵 등에서 실제 경로를 확인한 뒤 확정하세요.

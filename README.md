# 출장 방문순서 추천기

여러 곳을 출장 방문할 때, **어떤 순서로 돌면 이동거리가 가장 짧은지**를 알려 주는
HTML 파일 하나짜리 프로그램입니다.

- 설치할 프로그램이 없습니다. (Python, Node.js 설치 불필요)
- 서버, 데이터베이스, 회원가입, 로그인이 없습니다.
- `출장방문순서추천.html` 파일을 **더블클릭**하면 바로 실행됩니다.
- Chrome, Edge에서 사용합니다.

## 1. 실행 방법

1. `출장방문순서추천.html` 파일을 바탕화면 등 원하는 위치에 내려받습니다.
2. 파일을 **더블클릭**합니다. 기본 브라우저(Chrome 또는 Edge)에서 열립니다.
   - 다른 브라우저에서 열린다면 파일을 **마우스 오른쪽 버튼 → 연결 프로그램 → Chrome(또는 Edge)** 을 선택하세요.
3. 맨 위 **설정** 버튼을 눌러 카카오 JavaScript 키를 한 번만 입력합니다. (아래 2번 참고)
4. 출발지와 출장지를 검색해 등록하고 **최적 방문순서 추천** 버튼을 누릅니다.

> 장소 검색에는 인터넷 연결이 필요합니다.
> 이미 등록해 둔 장소의 방문순서 계산은 인터넷 없이도 동작합니다.

## 2. 카카오 JavaScript 키 발급 방법

무료로 발급받을 수 있습니다. 담당자 한 사람이 한 번만 발급하면 됩니다.

1. <https://developers.kakao.com> 에 접속해 **카카오 계정으로 로그인**합니다.
2. 상단 메뉴 **내 애플리케이션** → **애플리케이션 추가하기** 를 누릅니다.
3. 앱 이름(예: `출장 방문순서 추천기`), 사업자명(예: 부서명)을 입력하고 저장합니다.
4. 만들어진 앱을 클릭 → 왼쪽 메뉴의 **앱 키**(또는 **앱 설정 → 앱 키**) 화면으로 들어갑니다.
5. 거기에 표시된 **JavaScript 키** 를 복사합니다. (32자리 영문·숫자)
6. 프로그램의 **설정** 화면에 붙여넣고 **적용** 을 누릅니다.

### 꼭 구분해야 할 것

| 키 종류 | 이 프로그램에서 | 설명 |
|---|---|---|
| **JavaScript 키** | ✅ **사용합니다** | 브라우저에서 쓰는 키 |
| REST API 키 | ❌ 사용하지 않습니다 | 서버용 키. 절대 입력하거나 파일에 적지 마세요 |
| 네이티브 앱 키 | ❌ 사용하지 않습니다 | 모바일 앱용 |
| Admin 키 | ❌ 사용하지 않습니다 | 관리자용. 유출 시 피해가 큽니다 |

### JavaScript 키의 성격과 주의사항

JavaScript 키는 **브라우저가 직접 사용하는 값**이라 숨길 수 없습니다.
F12(개발자도구)나 소스보기로 누구나 볼 수 있으며, 이는 카카오의 설계상 정상입니다.
따라서 다음을 전제로 사용하세요.

- **도메인 등록으로 보호합니다.** 카카오 개발자 사이트에 등록한 주소에서만 그 키가 동작합니다.
- **유출되면 사용량이 소모됩니다.** 남이 내 키를 쓰면 내 앱의 일일·월간 무료 사용량(쿼터)이 깎여,
  정작 업무 중에 검색이 막힐 수 있습니다.
- **사용량이 비정상적으로 늘면 키를 재발급**(교체)하고, 기존 키는 폐기하세요.
- **키를 GitHub 같은 공개 저장소에 올리지 마세요.** 이 저장소의 HTML 파일에도 키가 들어 있지 않습니다.
- 이 프로그램은 키를 **설정 화면에서 사용자가 직접 입력**하도록 되어 있고,
  **"이 PC에 키를 저장합니다" 를 체크했을 때만** 브라우저 저장소에 남깁니다.
  공용 PC에서는 체크하지 마세요. **저장된 키 삭제** 버튼으로 언제든 지울 수 있습니다.

### 무료 사용량(쿼터)

카카오의 무료 사용량 정책과 수치는 **수시로 바뀌므로 이 문서에 적지 않습니다.**
현재 내 앱에 적용된 값은 카카오 개발자 사이트의
**내 애플리케이션 → (앱 선택) → 쿼터** 화면에서 직접 확인하세요.
한도를 넘기면 그날의 검색이 막히며, 유료 전환은 카카오 쪽에서 별도로 신청해야 합니다.

> 참고: 한 번 출장 계획을 세울 때 발생하는 검색은 보통 수 건 수준이라,
> 부서 단위 업무 용도로는 무료 범위를 넘기기 어렵습니다.
> 다만 키가 외부로 유출되면 이야기가 달라집니다.

## 3. 도메인 등록과 `file://` 문제

> **이 항목이 이 프로그램에서 가장 주의할 부분입니다. 먼저 읽어 주세요.**

### 도메인 등록 방법

카카오 지도 JavaScript SDK는 **등록된 주소에서만** 동작합니다.

1. 카카오 개발자 사이트 → **내 애플리케이션** → 앱 선택
2. **앱 설정 → 플랫폼** 에서 **Web 플랫폼 등록** → 사이트 도메인 입력
3. 추가로 **앱 키 → JavaScript 키 → `JavaScript SDK 도메인`** 항목에도
   사용할 주소가 등록되어 있어야 합니다.
   (메뉴 이름은 카카오 콘솔 개편에 따라 달라질 수 있습니다. "JavaScript SDK 도메인"이라는
   문구를 찾으세요. "제품 링크 관리"는 다른 기능이므로 여기에 등록해도 소용이 없습니다.)
4. 주소는 **프로토콜·호스트·포트까지 정확히** 일치해야 합니다.
   `http://localhost:8000` 과 `http://localhost:8080` 은 서로 다른 주소입니다.

### `file://` 로 열었을 때의 문제 — 확인된 사실과 확인되지 않은 사실

**확인된 사실**

- 브라우저가 `file://` 로 연 페이지는 origin(출처)을 **`null`** 로 취급합니다.
  이 상태에서는 서버로 보낼 "도메인"이 사실상 없습니다.
- 카카오 SDK의 인증 실패는 **401 (domain mismatched)** 로 나타나며,
  카카오 개발자 포럼에는 "등록한 도메인과 실제 실행 주소가 일치해야 한다"는 안내가 반복됩니다.
- 로컬에서 **웹 서버 주소**(예: `http://localhost:8000`)를 등록해 쓰는 방식은
  동작한 사례가 여러 건 보고되어 있습니다.

**확인되지 않은 사실 (중요)**

- `file://` 를 JavaScript SDK 도메인으로 등록하면 동작한다는 이야기가 인터넷에 있으나,
  **주로 모바일 웹뷰(WebView) 사례**이고, **데스크톱 Chrome / Edge에서 동작한다는 근거는 찾지 못했습니다.**
- **이 저장소에서는 실제 카카오 키로 `file://` 환경을 시험하지 못했습니다.**
  (개발 환경의 네트워크가 외부로 차단되어 있어 카카오 서버에 접속할 수 없었습니다.)
  따라서 **"로컬 파일에서 카카오 검색이 된다"고 보장하지 않습니다.**

### 그래서 어떻게 하나요 — 권장 순서

**① 먼저 그냥 해 보세요 (1분)**

1. 카카오 개발자 사이트에서 JavaScript SDK 도메인에 `file://` 를 등록해 봅니다.
   (입력이 거부되면 ②로 넘어가세요.)
2. `출장방문순서추천.html` 을 더블클릭해 열고, 설정에 키를 넣고 **적용**을 누릅니다.
3. 화면 위쪽 안내가 **초록색("장소 검색을 사용할 수 있습니다")** 으로 바뀌면 성공입니다.
   빨간색 오류가 뜨면 ②나 ③으로 가세요.

**② 검색 없이 쓰기 — 위도·경도 직접 입력 (설치 불필요, 항상 동작)**

프로그램의 2번 항목 안에 **"장소 검색이 안 될 때 — 위도·경도 직접 입력"** 이 있습니다.
검색을 쓸 수 없을 때는 이 영역이 **자동으로 펼쳐집니다.**

1. 브라우저에서 <https://map.kakao.com> 을 엽니다.
2. 방문할 장소를 찾아 지도 위에서 **마우스 오른쪽 버튼을 클릭**하면
   그 지점의 좌표(위도·경도)를 볼 수 있습니다.
3. 장소 이름, 위도, 경도를 프로그램에 입력하고 **출장지로 추가**를 누릅니다.

자주 가는 곳 10~20군데의 좌표를 한 번만 정리해 두면, 이후로는 복사·붙여넣기로 끝납니다.
방문순서 계산·거리·복사·인쇄 등 **나머지 기능은 모두 그대로 동작합니다.**

> 이 프로그램은 좌표를 **추측하거나 임의로 만들어 내지 않습니다.**
> 검색 결과의 좌표이거나, 사용자가 직접 확인해 입력한 좌표만 사용합니다.

**③ 부서에서 한 번만 설정하면 되는 방법 — 사내 공유폴더/인트라넷에 올리기**

HTML 파일을 부서 웹서버나 인트라넷 게시판에 올려 `https://...` 주소로 열고,
그 주소를 JavaScript SDK 도메인에 등록하면 검색이 정상 동작합니다.
파일 하나만 올리면 되므로 별도 서버 구축은 필요 없습니다.

## 4. 장소 검색 방법

### 출발지 (1번 항목)

- 기본 검색어로 **충주시청** 이 들어 있습니다. **검색 → 결과에서 선택** 해야 출발지가 확정됩니다.
  이름만으로는 위치를 정하지 않습니다.
- `충주시청`, `충주시청 제2청사` 버튼으로 바로 검색할 수 있습니다.
- **읍면동 행정복지센터…** 버튼을 누르면 충주시 읍면동 목록이 나옵니다.
  (검색어를 넣어 주는 기능일 뿐, 좌표는 검색 결과에서 가져옵니다.)
- 임의 장소나 도로명주소를 직접 입력해도 됩니다.

### 출장지 (2번 항목)

- 충주시 안이라면 무엇이든 검색할 수 있습니다.
  예) `충주경찰서`, `충주세무서`, `수안보면 행정복지센터`, `서충주신도시`,
  기업체·식당·상가 이름, `충주시 으뜸로 21` 같은 도로명주소
- **최대 8곳**까지 등록됩니다.
- 검색 결과에는 **장소명 / 도로명주소 / 지번주소 / 선택 버튼** 이 함께 나옵니다.
  같은 이름이 여러 개일 때는 **주소를 비교해서** 맞는 것을 고르세요.

### 두 가지 검색 방식

| 버튼 | 사용하는 기능 | 언제 쓰나 |
|---|---|---|
| **장소·건물명** | `kakao.maps.services.Places.keywordSearch()` | 상호·기관명으로 찾을 때 |
| **주소** | `kakao.maps.services.Geocoder.addressSearch()` | 도로명주소·지번주소로 찾을 때 |

한쪽에서 결과가 없으면 **자동으로 다른 방식으로 한 번 더 검색** 하고, 그 사실을 화면에 알려 줍니다.

### 검색이 잘 안 될 때

- 띄어쓰기를 바꾸거나 줄여서: `수안보면 행정복지센터` → `수안보면사무소`
- 지역명을 붙여서: `충주 세무서`
- 건물명 대신 도로명주소로: `충주시 으뜸로 21`
- 검색 방식을 **장소·건물명 ↔ 주소** 로 바꿔서

## 5. 최적 방문순서 계산 기준

- 검색으로 확보한 **위도·경도**만 사용합니다.
- 두 지점 사이 거리는 **Haversine 공식**(구면 위의 직선거리, 지구 평균 반지름 6,371.0088 km)으로 계산합니다.
- **출발지는 고정**하고, 출장지를 방문하는 **가능한 모든 순서를 전부 비교**해
  직선거리 합계가 가장 짧은 순서를 고릅니다. (근사치가 아닌 **정확한 최적해**)
  - 출장지 8곳이면 8! = **40,320가지**를 모두 계산합니다. PC에서 즉시 끝납니다.
  - 출장지를 8곳으로 제한한 이유가 이것입니다.
- **복귀 체크 시**: 마지막 출장지 → 출발지 거리까지 합계에 포함합니다.
- **복귀 체크 해제 시**: 마지막 출장지에서 끝납니다.
  복귀 여부에 따라 추천 순서 자체가 달라질 수 있으므로, 바꾼 뒤에는 다시 계산하세요.
- **같은 장소 중복 등록을 막습니다.** (같은 장소 ID / 30 m 이내 / 이름+주소 동일)
- **출발지와 같은 장소**는 출장지로 등록되지 않습니다.
- 좌표가 없는 검색 결과는 거리 계산을 할 수 없으므로 목록에서 제외하고, 그 사실을 알려 줍니다.

### 결과로 나오는 것

- 추천 방문순서 (순서도: `충주시청 → … → 충주시청`)
- 전체 방문 장소 수
- 구간별 직선거리 / 누적거리 / 총 직선거리
- **방문 순서 복사** 버튼 (메일·보고서에 붙여넣기)
- **인쇄** 버튼 (입력 영역은 빠지고 결과만 인쇄됩니다)
- 지점별 카카오맵 바로가기 링크 (참고용, 인터넷 연결 필요)

## 6. 실제 도로거리와의 차이

> **직선거리 기준 추천이며 실제 자동차 최단경로와 다를 수 있습니다.**

- 도로를 따라가는 거리가 아니라 **두 점을 잇는 직선(대권) 거리**입니다.
- **강·산·고속도로 나들목·일방통행·공사구간은 전혀 반영되지 않습니다.**
  충주처럼 남한강과 산지가 가로지르는 지역에서는 직선으로 가까워 보여도
  실제로는 멀리 돌아가야 하는 구간이 있습니다.
- **주행시간·소요시간은 계산하지 않습니다.** 실시간 교통량도 반영하지 않습니다.
- 방문 약속시간, 업무 체류시간도 고려하지 않습니다.

**이 프로그램은 "대략 이 순서가 합리적이다"를 빠르게 잡아 주는 용도입니다.**
최종 출장 계획은 추천 순서를 받은 뒤 카카오맵 등에서 실제 경로를 확인하고 확정하세요.

## 7. 문제가 생겼을 때

프로그램이 화면에 한국어로 원인을 안내합니다. 아래는 그 요약입니다.

| 증상 | 원인 | 조치 |
|---|---|---|
| 위쪽 안내가 노란색 "키가 입력되지 않았습니다" | 키 미입력 | 설정에서 JavaScript 키 입력 |
| 빨간색 "SDK를 불러오지 못했습니다" | 키 오류 / 도메인 미등록 / 네트워크 차단 / 쿼터 초과 | 아래 체크리스트 순서대로 확인 |
| "인터넷에 연결되어 있지 않습니다" | 네트워크 끊김 | 연결 확인 후 설정 → 적용 다시 누르기 |
| "검색 결과가 없습니다" | 검색어 문제 | 4번 항목의 "검색이 잘 안 될 때" 참고 |
| "검색 중 오류가 발생했습니다" | 도메인 / 쿼터 / 키 문제 | 개발자 사이트의 쿼터 화면 확인 |
| "최대 8곳까지" | 출장지 상한 | 하나 삭제 후 추가 |
| "이미 등록된 출장지입니다" | 중복 | 정상 동작입니다 |
| "출발지와 같은 장소입니다" | 출발지 중복 | 정상 동작입니다 |
| 한글이 깨져 보임 | 파일이 손상됨 | 파일을 다시 내려받기 (메신저로 주고받을 때 깨질 수 있음) |

### SDK를 못 불러올 때 체크리스트

1. 복사한 것이 **JavaScript 키**가 맞습니까? (REST API 키를 넣은 경우가 가장 흔합니다)
2. 키 앞뒤에 **공백이나 `KakaoAK` 같은 접두어**가 붙지 않았습니까?
3. 카카오 개발자 사이트의 **JavaScript SDK 도메인**에 현재 주소가 등록되어 있습니까?
   - 프로그램의 오류 안내가 **현재 주소를 그대로 보여 줍니다.** 그 값을 그대로 등록하세요.
   - `file://` 로 열었다면 3번 항목(`file://` 문제)을 다시 읽어 주세요.
4. 기관 방화벽·백신이 `dapi.kakao.com` 접속을 막고 있지 않습니까?
   브라우저 주소창에 `https://dapi.kakao.com` 을 직접 쳐서 응답이 오는지 확인해 보세요.
5. 오늘 사용량이 한도를 넘지 않았습니까? (개발자 사이트 → 쿼터)

### 그래도 안 되면

**2번 항목의 "위도·경도 직접 입력"을 쓰세요.** 검색만 빠질 뿐, 방문순서 추천은 정상적으로 동작합니다.

## 8. 직원들에게 배포하는 방법

HTML 파일 하나만 전달하면 끝입니다. 상황에 맞는 방법을 고르세요.

### 방법 A — 파일만 나눠 주기 (가장 간단)

1. `출장방문순서추천.html` 을 부서 공유폴더에 올리거나 메일로 보냅니다.
2. 직원은 파일을 **자기 PC에 내려받아** 더블클릭합니다.
   (공유폴더에서 바로 여는 것보다 내려받아 여는 편이 안정적입니다.)
3. 각 직원이 설정에서 **키를 한 번 입력**하고, "이 PC에 키를 저장합니다"를 체크합니다.
   - 같은 부서 안에서 **키 하나를 공유**해도 됩니다. 다만 사용량(쿼터)도 함께 나눠 쓰게 됩니다.
   - 키는 메신저 공개 대화방이 아니라 **내부 메일이나 업무포털**로 전달하세요.

> 메신저로 HTML 파일을 보내면 간혹 인코딩이 깨집니다.
> 압축(zip)해서 보내면 안전합니다.

### 방법 B — 인트라넷/부서 웹서버에 올리기 (검색 기능까지 확실하게)

1. 파일을 부서 웹서버나 인트라넷 게시판에 올려 `https://...` 주소를 만듭니다.
2. 그 주소를 카카오 개발자 사이트의 **JavaScript SDK 도메인**에 등록합니다.
3. 직원들에게는 **링크만** 보냅니다. 각자 키를 입력할 필요도 없게 하려면,
   관리자가 키를 넣고 "이 PC에 키를 저장"을 쓰는 대신 — 각 직원이 처음 한 번만 입력하면 됩니다.

> 이 방법이면 3번 항목의 `file://` 문제를 완전히 피할 수 있습니다.

### 방법 C — 키 없이 쓰기

키 발급이 어려운 상황이라면, 자주 가는 출장지 좌표표를 부서에서 한 번 만들어
직원들이 **위도·경도 직접 입력**으로 쓰게 할 수 있습니다. 검색만 빠지고 나머지는 동일합니다.

## 9. 검증 내용과 한계

### 포함된 파일

```
cj-trip-order/
├── 출장방문순서추천.html   ← 이 파일 하나가 프로그램 전부입니다
├── README.md               ← 이 문서
└── tests/
    └── verify.mjs          ← 개발자용 자동 검증 스크립트 (일반 사용자는 필요 없습니다)
```

### 자동 검증으로 통과한 항목 (78건, 모두 통과)

실제 배포 파일을 Chromium에서 **`file://` 주소로 직접 열어** 검증했습니다.

- HTML 파일 직접 실행, 내부 CSS/JavaScript 로딩, 한글 인코딩
- Haversine 거리 정확성
  (위도 1도 = 111.19 km, 적도 경도 1도 = 111.195 km, 서울시청~부산시청 ≈ 325 km, 대칭성)
- **최적화 정확성**: 출장지 1~8곳 × 복귀/미복귀 **174개 무작위 사례**에서,
  프로그램의 전수비교 결과를 **별도로 작성한 Held-Karp 동적계획법 구현**과 비교해
  최솟값이 모두 일치(최대 오차 2.8e-14). 8곳에서 40,320가지를 모두 비교하는 것도 확인
- 방문 순서의 중복·누락 없음, 구간 수와 합계 일치
- 출장지 추가·삭제, 8곳 등록, 9번째 거부, 중복 등록 거부, 출발지와 동일 장소 거부
- 검색 결과 선택(장소명 검색 / 주소 검색), 좌표 없는 결과 제외
- 복귀 여부에 따른 결과 변화(순서·구간 수·총거리)
- 결과 복사(클립보드 내용 확인), 인쇄 레이아웃(입력 영역 숨김)
- 오류 상황이 모두 **한국어**로 안내되는지 (키 없음 / API 오류 / 결과 없음 / 범위 밖 좌표 / 키 형식 오류)
- 모바일 폭 390px, PC 폭 1280px에서 가로 스크롤 없음

실행 방법(개발자용):

```bash
npm i -D playwright && npx playwright install chromium && node tests/verify.mjs
```

### 검증하지 못한 것 — 반드시 읽어 주세요

- **실제 카카오 API 호출은 한 건도 하지 않았습니다.**
  위 검증은 전부 **Mock(가짜) 카카오 SDK** 기준입니다.
  개발 환경의 네트워크가 외부로 차단되어 있어 `dapi.kakao.com` 에 접속할 수 없었습니다.
- 따라서 다음은 **확인되지 않았습니다.**
  - 실제 JavaScript 키로 SDK가 로드되는지
  - 실제 `keywordSearch()` / `addressSearch()` 응답 형식이 프로그램의 처리와 맞는지
  - **`file://` 에서 카카오 검색이 동작하는지** (3번 항목 참고)
  - 결과 표의 카카오맵 링크가 실제로 의도한 화면을 여는지
- **Chrome / Edge 실제 브라우저가 아니라 Chromium(두 브라우저와 같은 엔진)에서 시험했습니다.**
- 코드는 응답 형식 차이에 대비해 방어적으로 작성되어 있지만(콜백 인자 순서 자동 판별,
  좌표 누락 결과 제외, 타임아웃 처리), **실제 키로 한 번 확인하는 절차는 반드시 필요합니다.**

처음 사용하실 때 `충주시청` 검색이 정상적으로 되는지 먼저 확인해 보시고,
오류가 나면 7번 항목의 체크리스트를 따라가 주세요.
